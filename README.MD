# Sistem Kendaraan Operasional Dinas

Aplikasi web untuk mengelola data kendaraan operasional dinas.
Admin bisa melihat daftar kendaraan, menambah, mengedit, dan menghapus data kendaraan, serta mengatur pemegang dan perangkat daerah pemakai kendaraan.

## Fitur
- Login admin
- Lihat daftar kendaraan operasional
- Tambah kendaraan baru
- Edit kendaraan (nopol, jenis, merk, tahun, warna, kondisi, status, pemegang, perangkat daerah)
- Hapus kendaraan
- Kelola perangkat daerah
- Ubah password

## Teknologi
- PHP Native (tanpa framework)
- MySQL / MariaDB
- HTML + CSS sederhana
- XAMPP
